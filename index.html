Project Overview & Guide Summary

Domain: Health Informatics • Conversational AI • Neuro-Symbolic AI

✔ Z3 Logic Verified ⚠ Risk Control Active

Existing clinical-trial matching platforms assume a patient's medical record is completely known and apply vector similarity or LLMs to rank trials. However, real-world patient data is almost always incomplete, and traditional models struggle with hard logical constraints, negations, and exact thresholds. Ask What Matters treats patient information as a partially known state, using Z3 constraint satisfaction to classify trials into SAT (potentially eligible), UNSAT (ineligible), or UNKNOWN (missing information), actively asking questions that yield the highest reduction in uncertainty.

⚖ Contribution 1: Logic Constraints

Shifts from "how similar is this patient to this trial" to hard logical evaluation: determining which inclusion/exclusion rules are satisfied, violated, or missing.

💡 Contribution 2: Active Info Gain

Instead of asking static forms, the system calculates which missing patient variable resolves the highest number of UNKNOWN trial states.

🛡 Contribution 3: Guaranteed Referral

Incorporates a Conformal Risk Control layer to safely defer high-uncertainty or borderline cases to human trial coordinators rather than making unsafe decisions.

One-Minute Pitch for Your Project Guide

Use this exact pitch during panel evaluations or supervisor meetings

"Our project improves clinical-trial matching by treating eligibility as a logical constraint problem rather than a basic similarity-ranking problem. Existing systems take a fixed patient record and rank trials. Our system assumes patient information is partially known. It converts trial eligibility criteria into formal constraints using an LLM, evaluates them with the Z3 SMT solver into SAT, UNSAT, or UNKNOWN, and then actively asks the patient the question expected to resolve the maximum number of uncertain trials. Finally, rather than forcing uncertain cases into an arbitrary decision, it defers them with unresolved logical constraints to a human coordinator with calibrated statistical safety guarantees."

Project Execution Scope & Feasibility Tiers

Depending on time and compute constraints, the system can be delivered in three well-defined tiers:

Tier 1 Baseline MVP

Minimal Viable Version

Three-valued logic system (SAT/UNSAT/UNKNOWN). Converts criteria to Z3 logic and evaluates against TREC 2021/2022 patient profiles.

Tier 2 Recommended

Reduced Version

Adds the active dynamic questioning layer using greedy information gain calculation without the statistical conformal calibration layer.

Tier 3 Full Scope

Full System

Complete pipeline: BM25/MedCPT retrieval, Z3 constraint engine, Information-Gain dynamic agent, CADEC lay conversion, and Conformal Risk Control.

⚠ Crucial Caveat for Project Defense (Avoiding Panel Rejection)

Do NOT Claim:

"We are the first to combine LLMs and SMT logic solvers for clinical trial matching."

Why? SatIR and NeSy-CTM (2026) have already established basic constraint-based clinical trial matching architectures.

DO Claim:

"While systems like SatIR introduce constraint matching, our contribution is using constraint logic to drive active, information-optimal conversational questioning and statistically safe deferral to human coordinators when uncertain."

Data Resources & Metrics

Datasets, Evaluation Metrics & APIs

Detailed view of the required corpora, training benchmarks, and quantitative metrics to measure system success.

* Note: For reproducible evaluation, strictly keep TREC 2022 corpus isolated as your un-mixed test benchmark.
TREC Clinical Trials 2022 Primary Evaluation

50 official patient topics across 375,581 clinical trial descriptions. Official relevance judgments available.

Metrics: NDCG@10, P@10, RPrec, MRR
TREC Clinical Trials 2021 Dev / Training Set

75 patient topics. Use exclusively for prompt engineering, logic schema design, and local dev tuning.

Chia Corpus Constraint Parsing

1,000 trials with 12,409 annotated eligibility criteria, 41k entities & 25k relations (negations, scope, temporal, values).

CADEC Lexicon Layperson Agent

1,250 patient forum posts mapped to SNOMED CT and MedDRA. Used to format Z3 variables into layperson questions.

ClinicalTrials.gov API v2 Live Demo Connector

Provides live trial IDs, eligibility criteria text, minimum/maximum age, sex, and healthy volunteer status. No API key required.
